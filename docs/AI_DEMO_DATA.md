# Demo data written with AI

The workers, projects and tasks in `api/src/seed/demoData.ts` were written by an AI assistant (Claude) so the app looks realistic from the first run. The schedule is then generated by code (`api/src/seed/buildDemoData.ts`) so that it is always clash-free and lands on weekdays.

## What is in it

- 12 workers with different roles and hourly rates
- 6 projects covering every status (Planned, Active, On hold, Completed)
- 34 tasks with descriptions, priorities, estimates, due dates and who works on them
- about 120 schedule bookings (3 to 4 hour morning or afternoon blocks) leading up to each task's due date

Dates are stored as offsets from the Monday of the current week. Whenever you seed, the data is centred on "now": some work is finished, some is in progress this week, some is planned.

## The prompt

You can paste this into any AI assistant to generate a different set, then replace the arrays in `demoData.ts`:

> Generate realistic demo data for a project management app used by a 12-person software delivery team at a mid-sized company.
>
> Return TypeScript arrays matching these interfaces: `DemoWorker { firstName, lastName, email, role, hourlyRate }`, `DemoProject { key, name, description, status: 'Planned'|'Active'|'OnHold'|'Completed', startOffset, endOffset, budget, color }`, `DemoTask { project, title, description, status: 'Todo'|'InProgress'|'Blocked'|'Done', priority: 'Low'|'Medium'|'High'|'Critical', estimatedHours, dueOffset, assignees: string[] }`.
>
> Rules: 12 workers with diverse names and realistic roles (PM, developers, designer, QA, DevOps, data, security, writer) and emails at contoso.dev. 6 projects that use every status at least once; offsets are days relative to today (negative = past). 5 to 9 tasks per project; tasks in completed projects are Done; task status should make sense against its due date; 1 or 2 assignees per task chosen by role. Descriptions are one plain sentence. No real company or person names.

## Regenerate the SQL script

After editing `demoData.ts`:

```bash
cd api
npm run db:seed-sql      # rewrites database/seed.sql
npm run db:seed -- --force   # or load straight into Azure SQL
```

Always review AI-generated data before using it: check for anything that looks like a real person's details, and that statuses and dates make sense together.
